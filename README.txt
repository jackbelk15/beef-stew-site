Copy the contents of this folder to /volume1/docker/beef-stew-site/ and run:

docker compose up -d --force-recreate

This is now a static, single-page Nginx site. There is no application service, database, form, JavaScript, or writable container storage.

The supplied photographs are included as optimized WebP files under site/assets/images/. Keep the original JPG files elsewhere if you want archival copies.
